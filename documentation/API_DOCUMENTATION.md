# API Documentation

Base URL: `http://localhost:8080/api`

Swagger UI is generated by Springdoc at `/api/swagger-ui.html`.

## Authentication

- `POST /auth/register`
- `POST /auth/login`

JWT must be sent as `Authorization: Bearer <token>`.

## Disease Detection

- `POST /disease/detect`
- Role: `ROLE_FARMER`
- Multipart fields: `image`, optional `cropId`
- Returns disease name, confidence score, affected area, severity level, pesticides, fertilizers, prevention measures, recovery time, and stored image URL.

## Tickets

- `GET /tickets`
- `POST /tickets`
- `PATCH /tickets/{ticketId}/assign/{doctorId}`
- `PATCH /tickets/{ticketId}/status?status=RESOLVED&recommendation=...`
- `GET /tickets/{ticketId}/messages`
- `POST /tickets/{ticketId}/messages`

## Reports

- `GET /reports`
- `GET /reports/export.csv`

## Analytics

- `GET /analytics/dashboard`

## Notifications

- `GET /notifications`
- `GET /notifications/unread-count`

## WebSocket

Endpoint: `/api/ws`

- Subscribe: `/topic/tickets/{ticketId}`
- Send: `/app/tickets/{ticketId}/chat`
