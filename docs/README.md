# AI Powered Crop Disease Detection and Farmer Support Portal

Production-ready full-stack reference implementation for farmer crop-image diagnosis, doctor ticket workflows, admin analytics, real-time chat, notifications, and report exports.

## Modules

- Authentication: login, register, refresh token, forgot/reset/change password, JWT security.
- Farmer: dashboard, disease detection, history, tickets, chat, recommendations, reports, notifications, profile.
- Doctor: assigned tickets, analysis, recommendations, advice documents, chat, performance analytics.
- Admin: users, doctors, farmers, tickets, reports, analytics, audit logs, block/unblock.
- AI: pluggable `DiseaseDetectionProvider` with mock and TensorFlow-ready implementations.

Primary docs are also available in `documentation/`.
